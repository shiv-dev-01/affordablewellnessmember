# Affordable Wellness Member

Member portal for **Affordable Wellness**. Signed-in patients use this app for the account that belongs to Affordable Wellness.

The repository name is `affordablewellnessmember` because this project is the member code for Affordable Wellness.

## Stack

- React
- Vite
- React Router
- Axios
- Tailwind CSS
- Auth0
- TypeScript

## Requirements

- Node.js 18 or later
- npm

## Run locally

```bash
git clone https://github.com/shiv-dev-01/affordablewellnessmember.git
cd affordablewellnessmember
npm install
npm run dev
```

The dev server opens at http://localhost:5173.

## Scripts

| Command | What it runs |
| --- | --- |
| `npm run dev` | `vite` |
| `npm run build` | `tsc && vite build` |
| `npm run lint` | `eslint . --ext ts,tsx --report-unused-disable-directives --max-warnings 0` |
| `npm run preview` | `vite preview` |
